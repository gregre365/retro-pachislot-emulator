# Contributing

This project is a modified version of MAME and is not part of the MAME project.
Please do not report its problems to MAMEdev or MAME Testers.

- Bug reports: open an issue here. Never attach ROM files.
- ROMs are not provided.

---

このプロジェクトは MAME を改変したもので、MAME プロジェクトの一部ではありません。
不具合を MAMEdev や MAME Testers に報告しないでください。

- 不具合の報告: このリポジトリの Issue にお願いします。ROM ファイルは添付しないでください。
- ROM の提供はしていません。
